# ACP 실습 노트 주제 분류

공개 목록과 상세 화면은 CMS 원본 `src/content/resources/acp-lab-notes/**/meta.json`의 `authorName`을 주제 목록으로 읽는다. 주제 사이는 ` · `로 구분하며, 주제 이름 자체에는 가운데점·쉼표·파이프를 넣지 않는다. 다국어 명칭은 `src/copy/acpLabNotes.ts`에서 관리한다.

## 분류 기준

공개 필터는 아래 5개 주제와 `전체`로 구성한다. 글에서 직접 실습하거나 설명하는 **주요 목적**으로 분류한다. 이전 편을 언급하거나 마지막에 로그를 확인했다는 이유만으로 운영 관리 태그를 붙이지 않는다. 자원 분류와 운영 관리는 함께 사용할 수 있다.

| 주제 | 포함 기준 | 1~50편 검토 결과 |
|---|---|---|
| 도입 가이드 | 도입 필요성, 설치, 첫 연결, 실습을 통한 도입 검토 | 1, 2, 3, 50 |
| DB 접근 제어 | DB 연결·권한·데이터 보호·SQL 통제 및 DB에 특화된 업무. MCP를 통한 DB 조회 포함 | 3~15, 18, 19, 25, 27, 32~37, 39~42, 47~49 |
| 서버 접근 제어 | 서버 접속·명령·파일 전송·세션·계정 및 서버 그룹 | 22, 23, 24, 28, 30, 31, 38, 43, 46 |
| Kubernetes 접근 제어 | 클러스터·리소스·Pod 접근 정책과 작업 기록 | 26, 29, 44, 45 |
| 운영 관리 | 요청·승인, 감사·이력·녹화·보고서, 실시간 작업 대응, 그룹·관리자 역할·예외 만료·담당자·비밀번호·알림 관리 | 5, 6, 8, 11~21, 24, 28, 30, 32, 33, 37, 38, 39, 42, 45~49 |

## 경계 사례

- 5·6·11~13·28·37·39·42·48·49편의 요청·승인은 운영 관리에 포함한다.
- 18편은 **예외 만료 후의 관리**, 19편은 **변경 전후 값 확인**, 32편은 **실행 사유 기록**, 47편은 **차단 SQL 알림**을 실습하므로 DB 접근 제어와 운영 관리에 둔다.
- 21편은 **관리자 역할 분리와 감사 담당자의 기록 조회**를 실습하므로 운영 관리에 둔다.
- 24·45편은 서버·Pod의 **녹화 재생**이 주목적이므로 자원 태그와 운영 관리를 함께 붙인다.
- 25편은 MCP를 통한 **DB 조회와 기존 DB 권한 적용**을 실습하므로 DB 접근 제어에 포함한다. 한 편만 있는 MCP 연동 버튼은 별도로 두지 않는다.
- 50편은 연재 회고를 통해 도입 가치를 설명하므로 도입 가이드에 둔다. 개별 기능을 언급한다고 모든 기능 태그를 붙이지 않는다.

기존 `승인·감사·운영` 묶음은 세 개로 분리되어 모두 같은 23편을 노출했다. 이 업무들은 운영 관리 하나로 통합하고, 본문 검토에서 확인한 관련 글의 누락도 보완했다. 가져오기 스크립트에도 같은 배정을 반영한다. 새 글이나 CMS 수정 시에는 이 기준으로 다시 판단한다.
