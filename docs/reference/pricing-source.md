# 가격표 원본 구조

공개 가격 카드·비교표의 단일 원본은 `src/copy/plans/`다. `aip/`와 `acp/`를 나누고
각 폴더에 `aip-plans.ko.ts`처럼 제품·용도·언어를 드러내는 파일을 둔다. 각 원본에는 `productKey`, `locale`,
제품명과 그 제품의 플랜·금액·조건만 함께 둔다.

`index.ts`는 원본을 locale·제품별로 연결한다. `PlansPage`가 이 값을 직접 가져와
기존 카드와 AIP 비교표를 렌더링한다. 제품·언어 식별 필드는 화면에 출력하지 않는다.
별도의 챗봇용 가격 사본이나 숨겨진 공개 페이지를 만들지 않는다.

가격을 수정할 때는 해당 제품·언어 원본을 수정한다. 다른 제품의 가격이나 과거 미사용
비교표를 같은 파일에 추가하지 않는다. `types.ts`와 데이터 테스트가 제품 연결 및
플랜별 비교 행의 열 수를 확인한다. ACP의 기존 미사용 비교표는 화면에서 렌더링되지
않는 데이터였으며, 제품별 분리 시 제거했다.

이번 분리는 공개 카드의 문구·금액·지원 표기·CTA 및 AIP 비교표를 변경하지 않는다.
상업 정책의 실제 변경이 필요하면 별도 콘텐츠 변경으로 검토한다.
