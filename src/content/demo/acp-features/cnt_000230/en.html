Kubernetes operations through ACP MCP connect permitted cluster queries to an AI agent workflow. Operators find targets in natural language, request information, and continue with further analysis. Repeated discovery and inspection requests become a connected process for preparing Kubernetes operational information.

Connecting ACP to QueryPie AIP through Model Context Protocol (MCP) allows an agent to query cluster information in the Kubernetes Access Control (KAC) environment. This demo configures the ACP MCP connection and completes authentication before asking the agent for accessible clusters. After reviewing the list, the user requests a status analysis of the selected cluster.

Workflow

  • ACP MCP integration with AIP

    • Configure the ACP MCP connection and authenticate in AIP so the agent can use cluster query tools.

  • Accessible cluster discovery

    • Request a cluster list in natural language and review the clusters currently available to the user.

  • Cluster analysis requests

    • Select a cluster from the results and request a status analysis as the next step in the conversation.

More ways to use this workflow

Platform engineers can apply this flow to finding clusters for pre-deployment checks or reviewing resource status across environments. Adding queries supported by connected MCP tools and permitted for the user can extend it to node and workload status checks or information collection for initial troubleshooting.

Connect cluster discovery and inspection requests into an agent workflow for operations. Automate repeated discovery and preparation so the team can focus on interpreting each environment’s state, prioritizing checks, and deciding on follow-up actions.
