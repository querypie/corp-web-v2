금융, 커머스, 플랫폼 등의 기업에서는 수천, 수만 대의 DB에 다양한 민감 정보를 보유하게 됩니다. 물론 기업이 사용하는 클라우드와 데이터 웨어하우스, 그리고 다양한 BI 도구로 인해 이를 관리하는 보안 아키텍처도 복잡해집니다. 축적된 민감 정보에 대해 보안을 강화하고, 액세스 제어와 관리를 용이하게 하며, 보안의 안정성을 확보할 수 있도록 QueryPie의 DB 액세스 제어(QueryPie DAC)가 핵심적인 역할을 수행하고 있습니다. 멀티 클라우드 환경에서 방대한 민감 정보와 데이터를 안전하게 관리하는 방법에 대해 설명해 드리겠습니다.

[에피소드 2 주요 내용]

  • 멀티 클라우드 환경과 다양한 데이터베이스 사용 환경에서 액세스 제어를 간편하게 관리하는 방법

  • MongoDB, Hadoop 등 복잡한 환경에서의 DB 액세스 제어

  • NoSQL에서 관리가 어려운(스키마 프리) 민감 정보에 대한 용이한 관리 및 제어

  • 원장 데이터 관리
